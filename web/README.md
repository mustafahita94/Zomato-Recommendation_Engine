# Discover UI

Next.js App Router frontend for the Bangalore restaurant recommender.

## Setup

```bash
npm install
cp .env.local.example .env.local
```

## Develop

Start the FastAPI backend from the repo root (`uvicorn src.api.main:app --reload --port 8000`), then:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
